HoNTo: an HOmophily Network Tool

For any comment/need please contact Paolo Franciosa

A software prototype in Python 3 is provided for measuring the homophily/heterophily of a network as described in paper
A novel method for assessing and measuring homophily in networks through second-order statistics
http://arxiv.org/abs/2107.10037
accepted for publication in Scientific Reports,
by Nicola Apollonio, Paolo G. Franciosa, Daniele Santoni.

Software has been engineered by Fabio Cumbo, public versions are available at:

  • https://github.com/fabio-cumbo/hontoGit
  • https://pypi.org/project/honto/
